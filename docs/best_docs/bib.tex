Live preview is a feedback loop with a deadline. Every keystroke is a small bet that tectonic will catch up in time; every render that lags is felt as friction. Streaming inserts soften that loop --- characters arrive in CodeMirror before the compiler is asked to recompile, so the prose materializes visibly rather than appearing all at once.

Failure deserves the same treatment. When the compiler stumbles, the offending line gets a quiet red mark in the gutter and the parsed message floats next to it on hover --- so the loop stays tight even when the build doesn't.
