\section*{What works}

\begin{itemize}
  \item Tectonic builds on file change, debounced 400\,ms server-side.
  \item The browser editor uses CodeMirror with a stex syntax mode.
  \item A \texttt{PreToolUse} hook prevents the agent from clobbering
        edits made since its last read.
  \item Edits from either side propagate through a polling file watcher
        and a serialized render queue, so concurrent typing and agent
        writes don't orphan a tectonic run.
\end{itemize}


\section*{Streaming}

This paragraph is being inserted character by character through a small
\texttt{POST /api/stream} endpoint that broadcasts each character over
the same WebSocket the editor uses for live sync. The file on disk is
written once at the end, so tectonic renders a single time.

\[
  T(n) = n \cdot \Delta t_{\text{char}} + T_{\text{tectonic}}.
\]



\section*{Round trip}

This block was streamed in at $\sim 20$\,ms per character, then tectonic compiled the page once at the end:
\[
  T_{\text{visible}} = N \,\Delta t_{\text{char}} + T_{\text{compile}}.
\]
