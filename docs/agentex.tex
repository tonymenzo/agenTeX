\section*{What works}

\begin{itemize}
  \item Tectonic builds on file change, debounced 400\,ms server-side.
  \item The browser editor uses CodeMirror with a stex syntax mode.
  \item A \texttt{PreToolUse} hook prevents the agent from clobbering
        edits made since its last read.
  \item Edits from either side propagate through a polling file watcher
        and a serialized render queue, so concurrent typing and agent
        writes don't orphan a tectonic run.
\end{itemize}
