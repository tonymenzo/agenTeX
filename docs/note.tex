\section*{Session notes --- 2026-05-11}

Today's pass: the project moved from \texttt{aTeXi} to \texttt{agenTeX} top to bottom --- conda env, MCP server, tool names, CSS theme, storage prefix, the lot. Then a clutch of UX upgrades:
\begin{itemize}
  \item Inline tectonic errors: gutter dot, hover popup, line tint.
  \item A faint blue wash on whatever the agent just wrote, fading after fifteen seconds.
  \item Cite-as-you-type: typing \verb|\cite{| opens a dropdown of local keys followed by INSPIRE hits.
  \item Cursor and scroll preserved across tab switches.
  \item Flush-before-edit: when an agent reaches in, the browser commits its in-flight keystrokes first, so nothing gets clobbered mid-thought.
\end{itemize}

The throughline: keep the loop tight, and keep the user in control of where their words live.
